# Metadata viewer for NGFF RFC-8 collections

Web viewer for the NGFF RFC-8 collections metadata - see https://ngff.openmicroscopy.org/rfc/8/index.html.

⚠️ **WARNING**: This project is a proof of concept. It is experimental, unstable, and not intended for production use. Its functionality will evolve with RFC-8 progress.

## Supported format: RFC-8 revision 1

The viewer reads the **revision 1** proposal of RFC-8 (see the
[summary of changes](https://github.com/ome/rfc8-revision1/blob/main/rfc8_revision_changes.md)):

- nodes are `{type, id, name?, traits?}` with required UUID ids and optional names; there is no `attributes` field;
- `traits` is a list of typed objects (built-in keywords such as `plate`, `well`, `labels`, `scene`, or extension URIs declared in the document's `extension_manifest`);
- paths are `{type, format, href}` objects (`format` is `relative`, `absolute` or `http`), references are `{type, ref, path?}`;
- a multiscale is always its own document, with `coordinate_systems` and a `scales` list (the `singlescale` node type is gone). Traits on the node that declares a multiscale in a collection override same-type traits of the multiscale document.

Documents in the pre-revision format (`attributes`, `singlescale` nodes, `path.path`) are rejected with an explicit error. Structural camelCase keys from the upstream draft (`extensionManifest`, `coordinateSystems`, ...) are accepted. Node deep links in the URL hash are paths of UUIDs.

JSON Schema validation (`validate=true`) is currently disabled: the external [ngff-rfc8-validator](https://github.com/fractal-analytics-platform/ngff-rfc8-validator) only knows the pre-revision schema. The toggle stays and shows a notice instead.

## Quick start

The web viewer is available at https://fractal-analytics-platform.github.io/ngff-rfc8-viewer/.

Start with one of the following examples (generated by the scripts in [`examples/`](./examples/README.md) with [ngio-collections](https://github.com/BioVisionCenter/ngio-collections)):

- [Basic example: two images in a scene, one a label image](https://fractal-analytics-platform.github.io/ngff-rfc8-viewer/?source=https://raw.githubusercontent.com/fractal-analytics-platform/ngff-rfc8-viewer/main/examples/data/example1/zarr.json)
- [Many images in a collection](https://fractal-analytics-platform.github.io/ngff-rfc8-viewer/?source=https://raw.githubusercontent.com/fractal-analytics-platform/ngff-rfc8-viewer/main/examples/data/example2/zarr.json)
- [HCS plate with plate / well / acquisition traits](https://fractal-analytics-platform.github.io/ngff-rfc8-viewer/?source=https://raw.githubusercontent.com/fractal-analytics-platform/ngff-rfc8-viewer/main/examples/data/example4/zarr.json)
- [Collection of http paths to the other examples](https://fractal-analytics-platform.github.io/ngff-rfc8-viewer/?source=https://raw.githubusercontent.com/fractal-analytics-platform/ngff-rfc8-viewer/main/examples/data/example3/root.json)
- [Extensions: manifest, URI traits and a URI node type](https://fractal-analytics-platform.github.io/ngff-rfc8-viewer/?source=https://raw.githubusercontent.com/fractal-analytics-platform/ngff-rfc8-viewer/main/examples/data/example5/zarr.json)
- [Pre-revision document (legacy format error)](https://fractal-analytics-platform.github.io/ngff-rfc8-viewer/?source=https://raw.githubusercontent.com/fractal-analytics-platform/ngff-rfc8-viewer/main/examples/data/invalid/legacy/root.json)

To create new RFC-8 OME-Zarr collections, also check out the [ngio-collections](https://github.com/BioVisionCenter/ngio-collections) package.

## How to build the library

First build the viewer library:

```bash
cd lib
npm ci
npm run build
```

Then you can build the root project, which is a demo page calling the library:

```bash
npm ci
npm run build
```

## How to include the library

You can use the library including the files built in `lib/dist` in a HTML page:

```html
<link rel="stylesheet" href="ngff-rfc8-viewer.css" />
<script src="ngff-rfc8-viewer.umd.cjs"></script>
```

Have a look at the `index.html` source for a complete example.

## Development

To view the demo HTML page execute:

```bash
npm run dev
```

### pre-commit setup

In your local folder, create a file `.git/hooks/pre-commit` with the following content:

```bash
#!/bin/bash
cd lib && npm run pre-commit
RESULT=$?
[ $RESULT -ne 0 ] && exit 1
exit 0
```

and make this file executable (`chmod +x .git/hooks/pre-commit`).

In this way, `npm run pre-commit` will run before every commit.
